# Wedding Certificate — Adam & Maria 

A minimal, personal keepsake wedding certificate for Adam (`nova.af`) and Maria (`llittleaangel`).

---

## ✨ Features

- **Minimal Fine-Art Stationery:** Clean cotton-paper typography with quiet editorial serif styling.
- **Direct Inline Editing:** Tap or click anywhere on the certificate to edit names, Discord usernames, dates, or personal vows directly.
- **Hand-Drawn Signatures:** Sign with your hand, finger, touchscreen, or mouse directly on the signature lines.
- **High-Res Export:** Save as high-resolution PNG image or print/save as vector PDF.
- **Private & Local:** 100% client-side. Zero tracking, zero database, zero accounts.

---

## 🚀 Deploy on Vercel

1. Push this repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com/).
3. Framework Preset: **Other** (Static Site). No build command needed.
4. Deploy and share the link!
