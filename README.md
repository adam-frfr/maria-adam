# Our Little Forever 💍
### Standalone Discord Wedding Keepsake Certificate Generator

A romantic, playful, and elegant Discord wedding certificate generator website. Create, customize, sign, and download your personal keepsake certificate directly in the browser.

> **Note:** This certificate is a playful digital keepsake celebration and not a legal marriage certificate.

---

## ✨ Features

- **Personalised Details:** Customize both names, Discord tags, ceremony date, location/server/channel, officiant, and certificate title.
- **Vows & Keepsake Message:** Write your personal vows or choose from built-in presets (*Classic Sweet Romance*, *Discord Gamer & VC Soulmates*, *Our Little Forever*, *Nitro & Ping Promises*).
- **Dual Signatures (Spouse 1 & Spouse 2):**
  - **✍️ Draw:** Smooth touchscreen/mouse signature pad with clear and stroke smoothing.
  - **✒️ Type:** Elegant calligraphy font styles (*Pinyon Script*, *Great Vibes*, *Alex Brush*).
- **Three Luxury Themes:**
  - 👑 **Royal Champagne:** Ivory parchment paper, rich gold foil borders, and warm sand tones.
  - 🌸 **Blush Botanical:** Soft rose petals, botanical accents, and champagne gold.
  - 🌌 **Midnight Starlight:** Deep indigo obsidian paper, starry gold foil borders, and celestial crest.
- **High-Resolution Exports:**
  - **📥 Download PNG:** 300 DPI high-definition export powered by `html2canvas`.
  - **🖨️ Print / Save PDF:** Native `@media print` layout styled precisely for landscape A4 / US Letter.
- **Client-Side Privacy:**
  - 100% runs in your browser.
  - Zero databases, backend, accounts, or cookies required.
- **Shareable Link:**
  - Generates a shareable URL containing the couple's details via client-side hash (`#p1=...&p2=...`) without saving data to any server.
- **Discord Announcement Helper:**
  - 1-click button to copy formatted Discord markdown announcement for your server.
- **Celebration Effects:**
  - Confetti and golden petal cascades upon signing, downloading, or celebrating.

## 🚀 How to Deploy on Vercel

1. **Push or Import Repository:**
   - Push this repository to GitHub under your account.
2. **Import into Vercel:**
   - Go to [Vercel](https://vercel.com/) and click **Add New... > Project**.
   - Select your `maria-adam` repository.
3. **Deploy:**
   - Framework Preset: **Other** (Static Site).
   - No build command or output directory configuration needed.
   - Click **Deploy**.
4. **Share:**
   - Send the deployed URL to Angel or Maria! 💗

## 🛠️ Local Development & Testing

Since this project uses modern vanilla HTML, CSS, and JavaScript with CDN dependencies:
- Simply double click `index.html` or open it with any static server:
```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```
- Open [http://localhost:3000](http://localhost:3000) in your browser.
